# 固定画布布局编辑器

控制页在固定逻辑画布上编辑：横屏 480×320（0/180°），竖屏 320×480（90/270°）。
网页缩放只改变编辑视图，所有坐标和字号以设备逻辑像素保存。两种画布分别存储布局。
`layout.js` 的布局模型供控制页和 `/?display=1` 共用，设备页面不实例化编辑器。

## 使用

- 左侧元素列表列出 24 项：日期、星期、时钟、年度进度标签/条/百分比、城市、
  天气状况、温度、天气图标、高低温、湿度、降水概率、CPU、内存、IP、月历、
  三天天气、任务列表、照片、宠物、气泡、顶部横线和分栏竖线。
- 点击画布默认选择同组的可见元素；双击进入组内单选，Alt 点击也可单选。
  列表中点击直接单选，组标题选择整组；Shift 点击切换多选。重叠、隐藏及锁定元素
  可从列表选择，列表提供显隐与锁定按钮、搜索。
- 拖动使用 Pointer Events、指针捕获与画布实际缩放比换算坐标，释放时记一次撤销记录。
  鼠标与触摸共用实现。移动整体限制在画布内；锁定项不移动。Escape 取消当前拖动。
- 网格为 8px 可视辅助，吸附到画布及其他可见元素的边缘/中心；按 Alt 暂时关闭吸附。
  选择后在画布或元素列表按方向键移动 1px，Shift + 方向键移动 10px。
- 属性面板包括 X/Y、宽高、字号、颜色、长文字截断/换行、显隐与锁定；
  温度与高低温可分别选择摄氏度/华氏度，服务端天气原始数据仍为摄氏度。
  多选时宽高显示包围框尺寸且不可直接改，位置可整体调整。字号/颜色可批量修改。
- 在画布元素、空白处或左侧列表右击，打开元素操作菜单；右击已选项保留多选，
  右击其他元素按原有选组规则切换选区。菜单提供组合/取消组合、层级（顶层/底层）、
  元素对齐与等距分布、文字左/中/右对齐。锁定项不参与这些操作；等距至少需要三项。
  属性标题旁的“···”提供相同入口，便于触屏操作。
  在画布或列表按 Shift + F10 / 菜单键也可打开；方向键选择，→ 展开子菜单，
  ← 返回，Enter 执行，Esc 关闭并返回焦点；点击外部、滚动页面或改变窗口大小关闭。
  菜单靠近视窗边缘时自动避让。
  单选对齐以画布为参照，多选对齐以所选项包围框为参照。Delete/Backspace 隐藏所选未锁定项。
- 撤销重做最多保留 80 步，支持 Ctrl/⌘ Z、Ctrl/⌘ Shift Z、Ctrl/⌘ Y。
  数值/颜色连续输入在失焦时合为一步；刷新后只恢复草稿，不恢复撤销历史。
- 经典信息屏、大字时钟和专注任务模板仅替换当前方向的布局，可撤销。
  导入/导出 JSON 包含两套布局和屏幕方向，不含令牌、天气缓存或任务数据。

## 草稿与应用

布局、模板、方向的编辑不请求设备设置接口，草稿按同源地址保存在此浏览器
`localStorage`（键 `pidesk.layout-draft.v1`）。初次读取状态后恢复本地草稿，轮询不覆盖草稿。
本地存储失败时明确提示，离开未存储的草稿会触发浏览器离开提醒。
不同设备地址/端口各自保留草稿，设备 `display=1` 页面忽略浏览器草稿。

“应用到屏幕”先等待提示音/校色的已有保存请求，再将 `rotation` 和完整 `screen_layout`
一次提交给 `/api/settings`。成功应答后更新已应用基线并清除本地草稿；失败保留草稿供重试。
应用期间禁止布局修改。恢复已应用布局只恢复编辑草稿，可以撤销。
若其他控制页修改了设备布局，轮询会更新基线并提示当前草稿应用将替换设备布局。
这是覆盖提示，不提供多用户合并或版本锁。

声音提醒和屏幕校色继续自动保存。照片上传保存的是设备共享照片文件，上传本身立即替换
该文件；照片元素的显示/位置仍要应用布局。照片预处理沿用服务端当前方向的裁切规则。
实体屏幕/喇叭效果需对照硬件确认，接口成功仅表示软件设置已持久化。

## 配置协议

`screen_layout` 存为设备配置中的 `html_screen_layout`：

```json
{
  "version": 1,
  "landscape": {"clock": {"x": 30, "y": 60, "font": 56, "group": "none"}},
  "portrait": {}
}
```

各方向是元素 ID 到属性对象的映射。缺省属性继承该方向的内置默认布局；旧配置
没有 `html_screen_layout` 时仍按 `right_widget` 选择默认展示模块。编辑器读取时物化成完整布局，
之后可同时开启多个展示模块，`right_widget` 不再限制自定义布局的可见模块数量。
旧 `/api/rotation` 与 `right_widget` 接口保留；自定义元素的显式 visible 优先于旧模块选择。

字段严格校验，任一非法项导致整个设置请求 400，文件和内存均不改变：

| 属性 | 范围 |
|---|---|
| x / y | 画布内非负整数 |
| width / height | 1 至对应画布边长，显式位置与尺寸不得越界 |
| font | 8–96 整数 |
| color | `#RRGGBB` |
| visible / locked | 布尔值 |
| z | 0–100 整数 |
| align | `left` / `center` / `right` |
| overflow | `ellipsis` / `wrap` |
| unit | 仅 temperature / range：`c` 摄氏度 / `f` 华氏度 |
| group | 小写字母开头，字母数字连字符，最多 32 字符；`none` 表示不组合 |

不接受任意 HTML、CSS、URL 或脚本。后端的允许元素 ID 与前端默认布局通过离线测试对照。
布局参与渲染签名，应用后设备浏览器按新方向及布局重画，无需应用重启。
