# 界面与定制

控制网页采用元素列表、固定画布、属性面板三栏布局，窄屏自动分行。
桌面画布随页面滚动保持可见，预览下方显示当前方向与展示模块。
控制台与实体屏幕的字体、色彩样式分离。设备以 `/?display=1` 加载
同一份页面，隐藏控制区，按原生像素绘制。

## 小屏布局

横屏 480×320，竖屏逻辑画布 320×480。驱动不旋转，输出层按所选角度转置，
不对整张画面插值缩放。

- 顶部：完整日期及星期，CPU、内存和局域网 IP。
- 左侧：宽 172px，时间 56px，年度进度条作为分隔。
- 当前天气：城市与状况、温度与图标、底部数据，使用三行 grid 对齐。
  温度 60px，度数单独缩小。太阳裁去 SVG 画布留白，实际可见尺寸约 64px。
- 底部：当日高低温、湿度、降水概率，图标配数字，不显示中文标签。
- 右侧：留空、月历或从明天起的三天天气。

纯黑底色，无动画、渐变、文字发光、卡片边框。保留内部细分隔线。
中文采用用户实机对比选定的 Noto Sans CJK SC 真正 Bold，禁止合成粗体；
数字为 DejaVu Sans/Mono Bold。字体来自系统安装包，不依赖外部字体 CDN。
字体对比页保留在 `/font-check.html`。

## 控制区

控制页采用左侧元素列表、中间固定画布、右侧属性/声音/校色的布局。
所有屏幕元素都可在画布内拖拽、显隐、锁定及修改属性；布局与屏幕方向保存为浏览器草稿，
使用“应用到屏幕”才提交设备。横竖屏独立保存排布，网页缩放不改变设备像素。

分组、层级、元素及文字对齐收进画布/列表右键菜单，属性标题的“···”可打开相同菜单。
具体操作、分组、对齐、撤销重做、模板、导入导出及草稿恢复，见
[布局编辑器](layout-editor.md)。声音提醒与屏幕校色继续防抖自动保存，失败保留修改并可重试。
试听等待当前设置成功保存，播放在树莓派喇叭；RGB 增益只作用于实体屏幕输出，网页不模拟校色。

## 修改入口

- `app/web/index.html`：界面结构。
- `app/web/style.css`：字号、配色、布局、横竖屏适配。
- `app/web/app.js`：真实状态绑定、SVG 天气图标、控制事件。
- `app/src/pidesk/app.py`：HTTP、状态及写屏循环。

部署后网页文件变化约 5 秒自动触发小屏重载，浏览器控制页手动刷新。
屏幕截图保存于 `/run/pidesk-dashboard.png`，这是软件输出图，不是物理屏幕照片。
截图默认约每秒采样，处理过慢会自适应降低采样频率；像素无变化时不重复写屏。
该频率不是物理 SPI 屏幕的全屏帧率。

暗部色彩和全屏更新限制见 [硬件说明](hardware.md)。运行及回退见
[部署说明](deployment.md)，浏览器检查工具见 [开发说明](development.md)。
